# StaxTech Content Automation

This directory will contain the topic-to-article generator.

Current mode: **draft**.

Pipeline:

1. Discover candidate topics.
2. Score topics for relevance to StaxTech.
3. Generate a draft.
4. Run quality and SEO checks.
5. Keep the result as a draft for review.
6. Publish only after approval.

No automatic publishing is enabled yet.
